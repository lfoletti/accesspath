# Code of conduct

accesspath is a small project. Everyone who takes part in it, in issues, pull requests, discussions or any other
channel of the project, agrees to these rules.

## What we expect

- Be respectful and patient. Assume good faith, and remember that many contributors write in a second language.
- Discuss the work, not the person. Criticism of code, ideas and reports is welcome when it is specific.
- Accept a decision of the maintainer, or ask for its reasons; do not repeat the same request in many places.

## What is not accepted

- Harassment, insults, discriminatory remarks, and sexual language or images.
- Personal attacks, threats, and the publication of private information about anyone.
- Using the project to plan the abuse of a website: attacks, denial of service, or circumvention against the
  explicit refusal of its owner. accesspath reports how a site can be reached; it does not help to break in.

## Report

Report a problem to the maintainer through the address on the GitHub profile of
[@lfoletti](https://github.com/lfoletti). Reports are confidential. The maintainer can edit or remove contributions,
and can block a person from the project, temporarily or permanently.

This code takes its ideas from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
