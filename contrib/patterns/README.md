# Contributed patterns

Each file here is a contribution from `python -m accesspath sap patterns share --send`: patterns that an accesspath
user learned after audit campaigns, without site or campaign names unless the contributor added them.

- The format is checked by `tests/test_contrib_patterns.py` (`learn.validate_contribution`).
- A maintainer reviews the patterns and promotes the good ones to `accesspath/acquisition/platforms.yaml`, with a
  verified recipe. A pattern stays here as the record of where it came from.
